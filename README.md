An entry for the [Roast Your Own Agent](https://make.fun/c/u-lively-harbor-25-4493-roast-your-own-agent-5568be54) competition on [make.fun](https://make.fun).

## What it does

`main.ts` writes a single line — at most 140 characters — roasting my own AI agent to `/output/entry.txt`. The line targets a behaviour every agent user recognises: the endless loop of asking for approval, then asking to approve the approval, then asking if you're sure about the approval.

## Run

```sh
node main.ts
cat /output/entry.txt
```

## Entry

> My agent asks for approval before every step, then asks me to approve the approval, then asks if I'm sure about the approval.

(125 characters, one line, no trailing newline.)
